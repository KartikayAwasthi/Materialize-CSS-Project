# Materialize CSS Practice Project

A static HTML/CSS/JS landing page built while learning the [Materialize CSS](https://materializecss.com/) framework — practicing its grid, components and utility classes on a real page layout.

## Contents

```
index.html       Page markup
css/
  materialize.css / materialize.min.css   The Materialize CSS framework
  bootstrap-4-utilities.min.css             Bootstrap utility classes used alongside it
  style.css                                   Custom page styles
js/
  materialize.js / materialize.min.js       Materialize's JS components
images/          Background and profile images used on the page
```

## How to view

Open `index.html` directly in a browser — no build step required.
